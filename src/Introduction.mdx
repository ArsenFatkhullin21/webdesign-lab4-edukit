# EduKit — дизайн-система

Дизайн-система образовательной платформы (развитие сайта CodeLab из лабораторных №1–3). Токены описаны в формате **W3C Design Tokens**, CSS генерирует **Style Dictionary**, компоненты написаны на чистом HTML/CSS/JS и документированы в **Storybook**.

## Принципы

1. **Ясность** — компонент понятен без инструкции: видимые подписи, явные состояния.
2. **Консистентность** — одинаковые элементы выглядят и ведут себя одинаково; никаких «жёстких» цветов, только токены.
3. **Доступность** — WCAG 2.1 AA: контраст ≥ 4.5:1, видимый фокус, клавиатура, `prefers-reduced-motion`.
4. **Адаптивность** — компоненты работают от 320 px.
5. **Расширяемость** — новые варианты добавляются модификаторами `ds-*--variant`, существующий API не ломается (SemVer).

## Как устроено

| Слой | Что | Где |
|---|---|---|
| Токены | W3C JSON: примитивные → семантические; тёмная тема — отдельный набор | `tokens/` |
| CSS | генерируется Style Dictionary: `tokens.css` (`:root`) и `tokens-dark.css` (`[data-theme="dark"]`) | `src/styles/` |
| Компоненты | Atoms → Molecules → Organisms, у каждого `.js`, `.css`, `.stories.js` | `src/components/` |

## Темы

Тема переключается атрибутом `data-theme` на `<html>`. В Storybook — переключатель **Theme** в верхней панели. Компоненты используют только семантические токены, поэтому тёмная тема работает без правок компонентов.

## Подключение в проект

```html
<link rel="stylesheet" href="tokens.css">
<link rel="stylesheet" href="tokens-dark.css">
<link rel="stylesheet" href="components.css">
<html data-theme="dark">
```
